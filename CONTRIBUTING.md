## Development Setup

```bash
git clone https://github.com/Taam-dev/WFChessReviewerTdev.git
cd WFChessReviewerTdev
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
pip install -e .
playwright install chromium
